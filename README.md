# Arduino Robotic Arm

## Overview

A multi-axis robotic arm controlled using an Arduino Nano and servo motors.
The project was developed as part of my school robotics lab work and demonstrated
during the lab inauguration.

## Objective

The objective was to build a functional robotic arm capable of controlling
multiple joints through servo motors and demonstrating basic robotic motion.

## Hardware

- Arduino Nano
- 4 × Servo Motors
- Robotic arm structure
- External power supply
- Connecting wires
- 3d printed parts
## System Architecture

[Control Input]
       ↓
[Arduino Nano]
       ↓
[Servo Control]
       ↓
[4 Servo Motors]
       ↓
[Robotic Arm Movement]
